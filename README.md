# Macroeconomic DSGE Model: Fiscal Policy and Government Debt

Quantitative macroeconomic project developed as part of a Macroeconomics course, using **MATLAB and Dynare** to study the dynamic effects of fiscal policy in a DSGE framework.

The project analyses the response of key macroeconomic variables to government spending shocks and compares model specifications with and without government bonds.

## Project Overview

The project develops and simulates a dynamic macroeconomic model in which households and firms make intertemporal decisions and fiscal policy affects the economy through government expenditure and debt.

The analysis combines analytical model formulation with numerical implementation in MATLAB and Dynare.

Two model specifications are considered:

- A baseline model without government bonds
- An extended model incorporating government debt

This allows the role of government borrowing and fiscal dynamics to be examined within the model.

## Methodology

The project includes:

### Model Formulation

The theoretical model is derived from the optimization problems faced by economic agents and translated into a system of equilibrium conditions suitable for numerical simulation.

The model incorporates key macroeconomic relationships involving:

- Household consumption and saving decisions
- Labour supply
- Capital accumulation
- Production
- Wages and returns to capital
- Government expenditure
- Taxation
- Government debt

### Steady-State Computation

The steady state is computed numerically in MATLAB.

The implementation:

- Calibrates the structural parameters of the model
- Solves the nonlinear steady-state system
- Computes equilibrium values for consumption, capital, output, wages and fiscal variables
- Provides the steady-state values required for the subsequent Dynare simulations

### Dynare Simulation

The dynamic model is implemented in **Dynare** to analyse how the economy responds to fiscal shocks.

The simulations examine the responses of macroeconomic variables following changes in government expenditure and compare the dynamics generated by the alternative model specifications.

## Economic Interpretation

The project focuses not only on implementing the model computationally but also on understanding the economic mechanisms behind its results.

Impulse responses are used to analyse how fiscal shocks propagate through consumption, investment, labour, output and government finances over time.

The comparison between specifications illustrates how introducing government debt changes the transmission of fiscal policy within the model.
